# How the Internet Works — Resources

## Knowledge

- [Repo: alex/what-happens-when](https://github.com/alex/what-happens-when) (verified 2026-08-22)
  The canonical deep-dive on the classic interview question, keyboard interrupt to page render. Use for: lesson 1 source material, depth follow-ups.
- [Book (free online): High Performance Browser Networking — Ilya Grigorik](https://hpbn.co) (verified 2026-08-22)
  O'Reilly book, free. Chapters on TCP handshake, TLS, HTTP/1.1→2. Use for: transport-layer lessons, TLS, performance angle interviewers love.
- [Cloudflare Learning Center](https://www.cloudflare.com/learning/) (verified 2026-08-22)
  Clear, accurate explainers: DNS, TLS, CDN, DDoS. Use for: grounding each protocol lesson; DNS resolution steps verified against [What is DNS?](https://www.cloudflare.com/learning/dns/what-is-dns/).
- [Practical Networking (YouTube, free course)](https://www.practicalnetworking.net/series/networking-fundamentals/)
  Well-regarded video series on packets, switching, routing. Use for: visual reinforcement when a concept doesn't stick from text.

## Wisdom (Communities)

- [r/networking](https://www.reddit.com/r/networking/) — enterprise-leaning, strict moderation. Use for: "why does X really work this way" questions.
- [r/cscareerquestions](https://www.reddit.com/r/cscareerquestions/) — interview experiences and question reports. Use for: which networking questions actually get asked.
