# Starting point: codes, networks foggy

User writes code regularly and knows HTTP/APIs at the usage level, but the layers underneath (DNS, TCP, TLS) are self-described as fuzzy. Learning is for job interview prep, not production work.

**Implications:** Skip "what is a server" basics. Start at the end-to-end request journey (lesson 0001) and zoom into one layer per lesson. Anchor everything to the interview question "what happens when you type google.com".
