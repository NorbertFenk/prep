Your first useful program

In about fifteen minutes, you will read a real file from disk, handle the failure case properly, and process what you read — everything from lessons 1–11 in one program.

Builds on lesson 11 · one small project

1. Quick recall

Without looking back: what does a function conventionally return as its last result when it can fail?

2. Files fail, so files return errors

os.ReadFile reads a whole file in one call. The file might not exist, so it follows lesson 11's shape exactly — data first, error last:

data, err := os.ReadFile("names.txt")

data is a []byte — the file's raw contents. string(data) converts it to text, and strings.Split cuts that text into a slice at every separator you name.

3. Greet a file full of names

In your hello-go module, create names.txt next to main.go:

Ada
Grace
Alan

Then replace main.go with:

package main

import (
    "fmt"
    "os"
    "strings"
)

func main() {
    data, err := os.ReadFile("names.txt")
    if err != nil {
        fmt.Println("error:", err)
        return
    }
    names := strings.Split(strings.TrimSpace(string(data)), "\n")
    for _, name := range names {
        fmt.Println("Hello,", name)
    }
}
go run .

You should see three greetings. Then break it on purpose: rename names.txt and run again. You get error: open names.txt: no such file or directory and a clean stop — the return keeps the program from touching data that was never read. Rename the file back.
