Make Go run

In ten minutes, you will recognize the four pieces of a Go program and run one yourself.

No prerequisites · ~10 min

1. The shape

Go starts at main inside package main. Imports name code you want to use. Here, fmt.Println writes text followed by a newline.

package main

import "fmt"

func main() {
    fmt.Println("Hello, Go")
}

Save it as main.go. If Go is installed, run go run main.go. You should see Hello, Go.

2. Change one thing

Replace the message with a sentence about what you want to build in Go. Run it again. The goal is not originality; it is proving that you can edit, run, and observe a program.
