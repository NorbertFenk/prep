Go / Lesson 6

Group values into a type

In about ten minutes, you will define your own type with struct and keep a slice of them — the shape most real Go data lives in.

Builds on lesson 5 · one small project

1. Quick recall

Without looking back: what does _ do in for _, name := range names?

2. A struct bundles fields

When values belong together — a name and an age — put them in one type:

type person struct {
    name string
    age  int
}

This declares a new type named person with two fields. Build one with a literal naming each field, and read a field with a dot:

p := person{name: "Ada", age: 36}
fmt.Println(p.name)

3. A slice of structs

In your hello-go module, replace main.go with this — lesson 5's slice, upgraded so each element carries two values:

package main

import "fmt"

type person struct {
    name string
    age  int
}

func main() {
    people := []person{
        {name: "Ada", age: 36},
        {name: "Alan", age: 41},
    }
    for _, p := range people {
        fmt.Println(p.name, "is", p.age)
    }
}
go run .

You should see two lines. Inside the slice literal, person may be left out of each element — the slice's type is already known. Now add yourself as a third person, run it again, and check the output.
