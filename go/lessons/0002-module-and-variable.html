Go / Lesson 2

Give your program a value

In about ten minutes, you will put a Go program in a module and make its output depend on a variable.

Builds on lesson 1 · one small project

1. Quick recall

Without looking back: which function is the entry point of an executable Go program?

2. Create a module

In a terminal, make a fresh project directory and initialize it:

mkdir hello-go
cd hello-go
go mod init example.com/hello-go

The command creates go.mod. It gives this project a module path and records the Go version and future dependencies.

3. Add a variable

Create main.go with this program:

package main

import "fmt"

func main() {
    name := "Ada"
    fmt.Println("Hello,", name)
}

name := "Ada" declares and initializes name. Go infers that the value is a string. The next line prints both the fixed greeting and the current value.

go run .

You should see Hello, Ada. Change Ada to your own name, run it again, and observe the changed output.
