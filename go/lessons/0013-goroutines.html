Do things at the same time

In about ten minutes, you will run functions concurrently with the go keyword and wait for all of them with a WaitGroup — Go's headline feature.

Builds on lesson 12 · one small project

2. go starts a goroutine

Put go in front of a function call and it runs concurrently — a goroutine — while the caller keeps going. Goroutines are cheap; Go programs routinely run thousands.

That creates one problem: when main returns, the program exits, goroutines or not. sync.WaitGroup is the fix — a counter of pending work: Add(1) before starting each goroutine, Done() when it finishes, Wait() blocks until the counter hits zero.

Two details from earlier lessons show up: the WaitGroup is passed as a pointer (&wg) so Done() decrements the original, not a copy. And Done() is deferred — defer schedules a call for when the function exits, however it exits.

3. Greet four people at once

In your hello-go module, replace main.go with:

package main

import (
    "fmt"
    "sync"
    "time"
)

func greet(name string, wg *sync.WaitGroup) {
    defer wg.Done()
    time.Sleep(time.Duration(len(name)) * 100 * time.Millisecond)
    fmt.Println("Hello,", name)
}

func main() {
    names := []string{"Ada", "Grace", "Alan", "Edsger"}
    var wg sync.WaitGroup
    for _, name := range names {
        wg.Add(1)
        go greet(name, &wg)
    }
    wg.Wait()
    fmt.Println("all done")
}
go run .

Each goroutine sleeps 100ms per letter of its name, then greets. They all start together, so they finish in order of name length — Ada, Alan, Grace, Edsger — not the order they were started, and the whole program takes about 600ms, the longest sleep. Proof it is concurrent: delete the word go, run again, and watch the greetings come in start order — and take about 1.8 seconds. Put go back.
