Go / Lesson 3

Make it decide and repeat

In about ten minutes, you will give your program a loop and a decision — the two pieces that turn a script into something useful.

Builds on lesson 2 · one small project

1. Quick recall

Without looking back: which file identifies a directory as a Go module?

2. The only loop you need

Go has one looping keyword: for. Its three parts are initializer, condition, and post statement — no parentheses anywhere:

for n := 1; n <= 5; n++ {
    fmt.Println(n)
}

if looks the same way: condition, then braces. else is optional.

if n%2 == 0 {
    fmt.Println("even")
} else {
    fmt.Println("odd")
}

% is the remainder operator: n%2 is 0 exactly when n divides evenly by two.

3. Put them together

In your hello-go module from lesson 2, replace main.go with:

package main

import "fmt"

func main() {
    for n := 1; n <= 5; n++ {
        if n%2 == 0 {
            fmt.Println(n, "is even")
        } else {
            fmt.Println(n, "is odd")
        }
    }
}
go run .

You should see five lines alternating odd and even. Now change the loop to count to ten, run it again, and check the output matches what you expect.
