2. flag turns arguments into variables

The standard flag package binds a command-line flag to a variable. flag.String takes the flag's name, its default, and a help text — and returns a pointer to a string (lesson 9 pays off):

name := flag.String("name", "world", "who to greet")
flag.Parse()
fmt.Println(*name) // the value, through the pointer

flag.Parse() reads the actual command line; before it runs, the variables hold only defaults. After it, *name holds whatever -name said. The help texts are not decoration: -h prints them automatically, formatted.

3. Build greet, the tool

In your hello-go module, replace main.go with:

package main

import (
    "flag"
    "fmt"
    "strings"
)

func main() {
    name := flag.String("name", "world", "who to greet")
    shout := flag.Bool("shout", false, "greet loudly")
    flag.Parse()

    greeting := "Hello, " + *name
    if *shout {
        greeting = strings.ToUpper(greeting)
    }
    fmt.Println(greeting)
}
go run .
go run . -name Ada
go run . -name Ada -shout
go run . -h

Four runs, four behaviors — from the same binary: Hello, world, Hello, Ada, HELLO, ADA, and the auto-generated usage text. Notice a bool flag needs no value: -shout alone sets it true.
