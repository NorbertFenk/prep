2. Directories are packages

Inside a module, every directory is a package. Its import path is the module path plus the directory: in module example.com/hello-go, the directory greet/ is imported as "example.com/hello-go/greet". Every file in a directory starts with the same package line.

One rule guards the borders: a name is visible outside its package only if it starts with a capital letter. Hello is exported; decorate is private to its package. There is no export keyword — case is the whole mechanism.

3. Move greet out of main

In your hello-go module, create the directory greet and inside it greet/greet.go:

package greet

func Hello(name string) string {
    return decorate("Hello, " + name)
}

func decorate(s string) string {
    return ">> " + s + " <<"
}

Then replace main.go with:

package main

import (
    "fmt"

    "example.com/hello-go/greet"
)

func main() {
    fmt.Println(greet.Hello("Ada"))
}
go run .

You should see >> Hello, Ada <<. Note the call shape: greet.Hello — package name, dot, exported name, exactly like fmt.Println; you have been using other people's packages since lesson 1. Now try calling greet.decorate("x") from main and read the compiler's complaint: lowercase names do not cross package borders. Delete the call.
