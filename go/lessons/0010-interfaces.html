One function, many types

In about ten minutes, you will write an interface, satisfy it without declaring that you did, and make fmt.Println print your struct however you like.

Builds on lesson 9 · one small project

2. An interface is a list of methods

An interface names behavior, not data. Any type that has the listed methods satisfies it — automatically, with no implements keyword anywhere:

type greeter interface {
    greet() string
}

Lesson 8's person already has greet() string, so person is a greeter. A function taking greeter now accepts person — and any future type that grows a greet method, without editing the function.

The standard library plays the same game. fmt.Stringer is just String() string: give your type that method and fmt.Println calls it on its own. Without it, a person prints as the raw fields {Ada 36}.

3. Teach fmt about your type

In your hello-go module, replace main.go with:

package main

import "fmt"

type person struct {
    name string
    age  int
}

func (p person) String() string {
    return fmt.Sprint(p.name, " (", p.age, ")")
}

func (p person) greet() string {
    return "Hello, " + p.name
}

type greeter interface {
    greet() string
}

func announce(g greeter) {
    fmt.Println("Please say:", g.greet())
}

func main() {
    ada := person{name: "Ada", age: 36}
    fmt.Println(ada)
    announce(ada)
}
go run .

You should see Ada (36) — the String method at work — then Please say: Hello, Ada. Now define a second type robot with an id int field and its own greet, pass one to announce, and run again: the same function, a different type, zero changes to announce.
