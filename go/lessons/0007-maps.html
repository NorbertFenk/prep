Go / Lesson 7

Look things up by key

In about ten minutes, you will count words with a map — the data structure behind lookups, tallies, and caches in nearly every real Go program.

Builds on lesson 6 · one small project

1. Quick recall

Without looking back: in p := person{name: "Ada", age: 36}, what happens to a field you leave out?

2. A map connects keys to values

A slice finds things by position; a map finds things by key. In map[string]int, string is the key type and int is the value type:

ages := map[string]int{
    "Ada":  36,
    "Alan": 41,
}
ages["Grace"] = 45
fmt.Println(ages["Ada"])

The trick that makes counting work: reading a missing key returns the value type's zero value — 0 for int — instead of failing. So counts[word]++ turns a missing key into 1 all by itself.

3. Count words

In your hello-go module, replace main.go with this — lesson 5's slice feeds the map:

package main

import "fmt"

func main() {
    words := []string{"go", "run", "go", "build", "go"}
    counts := map[string]int{}
    for _, word := range words {
        counts[word]++
    }
    for word, n := range counts {
        fmt.Println(word, n)
    }
}
go run .

You should see go 3, run 1, build 1 — but in a different order on almost every run. Map order is deliberately unpredictable; never depend on it. Add a few more words to the slice and check the counts.
