Finish the conversation

In about ten minutes, you will close a channel so range can end on its own, and give a program a second thing to wait for with select.

Builds on lesson 19 · one small project

1. Quick recall

Without looking back: on an unbuffered channel, when does a send finish?

2. The sender closes

Lesson 14 counted receives by hand because it knew how many were coming. When only the sender knows when it is done, it says so: close(ch). Receivers can then loop with for msg := range ch, which ends by itself once the channel is closed and drained. The sender closes — a receiver cannot know if more values are coming, and closing twice, or sending on a closed channel, panics.

3. Stream until done

In your hello-go module, replace main.go with:

package main

import (
    "fmt"
    "time"
)

func greetAll(names []string, ch chan string) {
    for _, name := range names {
        time.Sleep(time.Duration(len(name)) * 100 * time.Millisecond)
        ch <- "Hello, " + name
    }
    close(ch)
}

func main() {
    names := []string{"Ada", "Grace", "Alan"}
    ch := make(chan string)
    go greetAll(names, ch)
    for msg := range ch {
        fmt.Println(msg)
    }
    fmt.Println("all done")
}
go run .

You should see the three greetings, then all done — no counting loop, no WaitGroup. The range ended because the sender closed. Try commenting out close(ch) and rerunning: main waits forever at the end of the range and the runtime kills it with fatal error: all goroutines are asleep - deadlock! — Go noticed nobody can ever make progress again. Restore the close.

4. Wait for whichever comes first

select waits on several channel operations and runs whichever becomes ready first — the tool for timeouts. Replace main.go's main with:

func main() {
    ch := make(chan string)
    go func() {
        time.Sleep(200 * time.Millisecond)
        ch <- "Hello, Ada"
    }()
    select {
    case msg := <-ch:
        fmt.Println(msg)
    case <-time.After(50 * time.Millisecond):
        fmt.Println("too slow, moving on")
    }
}

(The go func() { ... }() shape defines an anonymous function and starts it as a goroutine in one step.) Run it: the greeting needs 200ms but the timeout fires at 50ms, so you get too slow, moving on — deterministically. Now raise 50 to 300 and rerun: the greeting wins the race. That is the whole idea — first case ready, first case run.
