Go / Lesson 5

Work with a list of values

In about ten minutes, you will store several values in one slice and loop over them with range — the way almost every real Go program handles collections.

Builds on lesson 4 · one small project

1. Quick recall

Without looking back: in name := "Ada", what does Go figure out for you?

2. A slice holds many values

A slice is a list that can grow. []string{"Ada", "Grace"} is a slice literal — the element type in brackets, the values in braces. append adds an element and gives you the longer slice back, so you assign the result:

names := []string{"Ada", "Grace"}
names = append(names, "Alan")

range walks a slice, handing you two values per step: the index and the element. When you don't need the index, discard it with _:

for _, name := range names {
    fmt.Println(name)
}

3. Greet the list

In your hello-go module, replace main.go with this — it reuses the greet function you were asked to write in lesson 4:

package main

import "fmt"

func greet(name string) string {
    return "Hello, " + name
}

func main() {
    names := []string{"Ada", "Grace", "Alan"}
    names = append(names, "Edsger")
    for _, name := range names {
        fmt.Println(greet(name))
    }
}
go run .

You should see four greetings. Now replace "Edsger" with your own name, run it again, and check your greeting appears last.

4. Retrieve

What does []string{"Ada", "Grace"} create?

In for i, name := range names, what is name?

Why must you write names = append(names, "Alan")?
