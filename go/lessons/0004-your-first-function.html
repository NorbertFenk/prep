Go / Lesson 4

Give your code a name

In about ten minutes, you will move logic out of main into your own function — the step that makes programs reusable instead of one long script.

Builds on lesson 3 · one small project

1. Quick recall

Without looking back: how many times does for n := 1; n <= 5; n++ run its body?

2. Anatomy of a function

func parity(n int) string {
    if n%2 == 0 {
        return "even"
    }
    return "odd"
}

Read the signature left to right: keyword func, name parity, parameter n of type int, and a result of type string. Unlike :=, parameters always name their type explicitly. return hands a value back to the caller and ends the function — the if needs no else here.

3. Refactor lesson 3

In your hello-go module, replace main.go with:

package main

import "fmt"

func parity(n int) string {
    if n%2 == 0 {
        return "even"
    }
    return "odd"
}

func main() {
    for n := 1; n <= 5; n++ {
        fmt.Println(n, "is", parity(n))
    }
}
go run .

The output is identical to lesson 3 — that is the point. Same behavior, but the decision now lives in one named, testable place. Add a greet(name string) string function that returns "Hello, " + name, call it from main, and run again.
