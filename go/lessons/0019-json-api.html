Speak the web's language

2. encoding/json sees exported fields only

The standard library converts structs to JSON with encoding/json — and lesson 17's rule follows you here: only capitalized fields make it into the output. Lowercase fields are silently skipped, which surprises everyone exactly once.

A struct tag — text in backticks after a field — controls the JSON name:

type person struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

Now the JSON says "name", web-style lowercase, while the Go field stays Name, Go-style capital. And encoding needs no file or socket of its own: json.NewEncoder(w).Encode(v) writes v's JSON straight into anything that accepts writes — including lesson 18's w.

3. Serve JSON

In your hello-go module, replace main.go with:

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

type person struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func people(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode([]person{
        {Name: "Ada", Age: 36},
        {Name: "Alan", Age: 41},
    })
}

func main() {
    http.HandleFunc("/people", people)
    fmt.Println("listening on :8090")
    if err := http.ListenAndServe(":8090", nil); err != nil {
        fmt.Println("error:", err)
    }
}
go run .

In a second terminal:

curl http://localhost:8090/people

You should see [{"name":"Ada","age":36},{"name":"Alan","age":41}]. Now run the experiment that teaches the rule forever: change the tags to nothing at all — Name string and Age int, backticks deleted — restart, curl again, and watch the keys become "Name" and "Age". Then lowercase the fields (name string) and watch them vanish: [{},{}]. Restore the tags.
