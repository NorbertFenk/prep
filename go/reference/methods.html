Methods

A method is a function attached to a type via a receiver — data and behavior in one place.

Anatomy

func (p person) greet() string {
    return "Hello, " + p.name
}

ada := person{name: "Ada"}
fmt.Println(ada.greet())
PartMeaning
(p person)Receiver: the type the method attaches to, and the name it is known by inside the body.
ada.greet()Call on a value of the receiver's type; no manual passing of ada.
p.nameThe receiver's field, read with a dot.

Function vs method

ShapeMeaning
func greet(name string) stringPlain function; data arrives as a parameter.
func (p person) greet() stringMethod; data arrives as the receiver.

Value vs pointer receivers

(p person) copies the value — the method cannot change the original. (p *person) receives a pointer, so p.age = 37 sticks. Use pointer receivers for anything that mutates or is large; pick one style per type.
