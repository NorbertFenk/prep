Structs

A struct bundles named fields into one new type — the way related values travel together.

Declare, build, read

type person struct {
    name string
    age  int
}

p := person{name: "Ada", age: 36}
fmt.Println(p.name, p.age)
SyntaxMeaning
type person struct { ... }Declares a new named type with the listed fields.
person{name: "Ada", age: 36}Literal naming each field; unlisted fields get their zero value (0, "").
p.nameRead a field with a dot; p.age = 37 writes one.

Structs in slices

people := []person{
    {name: "Ada", age: 36},
    {name: "Alan", age: 41},
}
for _, p := range people {
    fmt.Println(p.name, "is", p.age)
}

Inside a slice literal, the element type may be left out of each entry — people already says it is person.
