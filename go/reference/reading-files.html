Go quick reference

Reading files

Small files: one call, one check. os.ReadFile returns bytes and an error.

The whole-file pattern

data, err := os.ReadFile("names.txt")
if err != nil {
    fmt.Println("error:", err)
    return
}
names := strings.Split(strings.TrimSpace(string(data)), "\n")
SyntaxMeaning
os.ReadFile(path)Reads the whole file; returns ([]byte, error). Missing file → non-nil error, no crash.
string(data)Converts raw bytes to text.
strings.TrimSpace(s)Cuts leading/trailing whitespace — including the final newline most files end with.
strings.Split(s, "\n")Cuts text into a slice of lines.

Importing several packages

import (
    "fmt"
    "os"
    "strings"
)

One import may be written bare (import "fmt"); two or more use the parenthesized block, conventionally in alphabetical order.

Paths and next steps

Relative paths resolve against the directory the program runs in, not where its source lives — run go run . from the module directory. For large files, stream instead of loading: bufio.Scanner over os.Open (see Go by Example).
