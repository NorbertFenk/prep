Go quick reference

Maps

A map connects keys to values for fast lookup — map[keyType]valueType.

Build and use

SyntaxMeaning
map[string]int{"Ada": 36}Map literal: key type, value type, entries in braces.
make(map[string]int)Empty map, same as map[string]int{}.
ages["Grace"] = 45Insert or overwrite an entry.
ages["Ada"]Read a value; a missing key yields the value type's zero value (0, "") — never an error.
counts[word]++The counting idiom: missing key reads as 0, becomes 1.
delete(ages, "Ada")Remove an entry; deleting a missing key does nothing.
len(ages)Number of entries.

Test and iterate

SyntaxMeaning
v, ok := ages["Ada"]Comma-ok: ok is false when the key is missing — how you tell "absent" from "zero".
for k, v := range agesVisit every entry in an unpredictable order; varies between runs by design.

A nil map (declared with var m map[string]int, never initialized) can be read but writing to it panics — always initialize before storing.
