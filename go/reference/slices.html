Slices and range

A slice is a growable list of elements of one type; range walks it.

Build and grow

SyntaxMeaning
names := []string{"Ada", "Grace"}Slice literal: element type in brackets, values in braces.
names = append(names, "Alan")Adds an element and returns the longer slice — always assign the result.
len(names)Number of elements.
names[0]First element; indexes start at 0.

Loop with range

SyntaxMeaning
for i, name := range namesTwo values per step: index i and element name.
for _, name := range namesElement only; _ discards the index.
for i := range namesIndex only.

Prefer slices over arrays: arrays have a fixed size baked into their type ([3]string), slices do not.
