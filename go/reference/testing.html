Go quick reference

Testing

Built in: files ending _test.go, functions TestXxx(t *testing.T), command go test.

A minimal test

package main

import "testing"

func TestDivide(t *testing.T) {
    got, err := divide(10, 2)
    if err != nil {
        t.Fatal(err)
    }
    if got != 5 {
        t.Errorf("divide(10, 2) = %d, want 5", got)
    }
}
SyntaxMeaning
t.Errorf(format, ...)Log a failure; the test continues and is marked failed.
t.Fatalf(format, ...)Log a failure and stop this test now.
t.Skip("reason")Mark the test skipped.

Running tests

CommandMeaning
go test .Run all tests in the current package.
go test ./...Run tests in every package of the module.
go test -v .Verbose: name each test and its result.
go test -run ByZero .Only tests whose name matches the pattern.

Table-driven tests

The Go idiom for many cases of one function — a slice of anonymous structs, looped with t.Run:

tests := []struct {
    a, b int
    want int
}{
    {10, 2, 5},
    {9, 3, 3},
}
for _, tt := range tests {
    t.Run(fmt.Sprint(tt.a, "/", tt.b), func(t *testing.T) {
        if got, _ := divide(tt.a, tt.b); got != tt.want {
            t.Errorf("got %d, want %d", got, tt.want)
        }
    })
}

Conventions: test file lives beside the code (divide_test.go), same package; name tests for the behavior (TestDivideByZero); a passing test suite prints just PASS plus timing.
