Go quick reference

HTTP server

net/http: register a handler per path, block on ListenAndServe. No framework needed.

The whole server

func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello,", r.URL.Path)
}

func main() {
    http.HandleFunc("/", hello)
    if err := http.ListenAndServe(":8090", nil); err != nil {
        fmt.Println("error:", err)
    }
}
PartMeaning
w http.ResponseWriterWrite the response here: fmt.Fprintln(w, ...), w.Write(bytes).
r *http.RequestThe request: r.URL.Path, r.Method, r.Header, r.FormValue("q").
http.HandleFunc(path, fn)Routes every path under path to fn; "/" catches all.
http.ListenAndServe(addr, nil)Binds the port and blocks, serving forever; returns only on error (e.g. port taken). nil = use the default router HandleFunc registered with.
w.Header().Set("Content-Type", ...)Set headers before the first write.
http.Error(w, "nope", 404)Send a status code and plain-text body.

Facts worth knowing

Each request is served in its own goroutine — concurrency is free, but shared state across handlers needs a mutex or channels. Status defaults to 200 on first write; set another with w.WriteHeader(404) before writing the body. Stop a dev server with Ctrl-C. Test it with curl http://localhost:8090/path.
