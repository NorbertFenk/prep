Go quick reference

Pointers

A pointer holds the address of a value — pass one and changes reach the original.

The two operators

SyntaxMeaning
&xAddress of x — produces a pointer.
*pFollow pointer p to the value it points at (read or write).
p := &np has type *int if n is an int.
var p *intZero value is nil — points at nothing; writing through it panics.

Pointer receivers

ShapeMeaning
func (p person) String() stringValue receiver: works on a copy; cannot change the original.
func (p *person) birthday()Pointer receiver: changes stick on the caller's value.
p.age++No (*p).age needed — Go applies the dot through pointers.
ada.birthday()No (&ada) needed — Go takes the address automatically.

Rules of thumb: mutate → pointer receiver; large struct → pointer receiver (skips the copy); otherwise either — but pick one style per type, since a type's method set should stay consistent.

Go has no pointer arithmetic: you can follow a pointer, but not walk it like C.
