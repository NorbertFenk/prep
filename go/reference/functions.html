Go quick reference

Functions

A function names a piece of logic, takes typed parameters, and hands back a typed result.

Anatomy

func parity(n int) string {
    if n%2 == 0 {
        return "even"
    }
    return "odd"
}
PartMeaning
funcKeyword that starts every function declaration.
parityName; call it as parity(4).
(n int)Parameter list — parameters always state their type explicitly, unlike :=.
stringResult type; omitted when the function returns nothing.
return "even"Sends a value to the caller and ends the function immediately.

Shapes worth knowing

SyntaxMeaning
func log(msg string)No result — called for its effect.
func divmod(a, b int) (int, int)Two parameters sharing a type; two results returned together.
q, r := divmod(7, 3)Caller receives multiple results into multiple variables.
