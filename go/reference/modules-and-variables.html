Go quick reference

Modules and variables

A module gives a Go project an identity; a variable gives a program a value to use.

Start a module

mkdir hello-go
cd hello-go
go mod init example.com/hello-go

This creates go.mod, which records the module path and Go version, then can record dependencies as the project grows.

Declare and use a value

name := "Ada"
fmt.Println("Hello,", name)
SyntaxMeaning
name := "Ada"Declare name and initialize it; Go infers its type.
fmt.Println("Hello,", name)Print fixed text and the current value of name.

:= is for declaring a new variable inside a function. Use var when you need a different declaration shape.
