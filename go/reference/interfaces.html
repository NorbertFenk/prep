Go quick reference

Interfaces

An interface names behavior; any type with those methods satisfies it — implicitly, no declaration needed.

Declare and satisfy

type greeter interface {
    greet() string
}

func (p person) greet() string { return "Hello, " + p.name }
// person is now a greeter — nothing else to write.
SyntaxMeaning
type greeter interface { ... }Declares a method set; usually one or two short methods.
func announce(g greeter)Accepts any type satisfying the interface — now and later.
var g greeterZero value is nil; calling a method on it panics.

Go's conventions

Interfaces are small — one method is the classic (Stringer, Reader, Writer). Define them where they are used, not where the types live. Lowercase method names (like greet) only satisfy interfaces within the same package; exported interfaces list exported methods.
