Go quick reference

Control flow: if and for

Go has one loop keyword and one decision keyword. Neither condition takes parentheses.

Loops

SyntaxMeaning
for n := 1; n <= 5; n++ { ... }Three-part loop: initializer, condition, post statement. Body runs while the condition is true.
for n < 10 { ... }Condition-only loop (Go's "while").
for { ... }Endless loop; leave it with break or return.

Decisions

SyntaxMeaning
if n%2 == 0 { ... }Run the body when the condition is true. No parentheses around the condition; braces are required.
} else { ... }Optional alternative branch, on the same line as the closing brace.
n % 2Remainder of n divided by 2; 0 means even.
== vs === compares, = assigns. Conditions use ==.

There is no while, do, or repeat in Go — every loop is a for.
