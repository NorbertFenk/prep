Go quick reference

JSON

encoding/json converts structs ⇄ JSON. Exported fields only; tags control names.

Struct to JSON (encode)

type person struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

json.NewEncoder(w).Encode(p)  // writes into any writer — HTTP response, file, buffer
b, err := json.Marshal(p)     // or get a []byte
SyntaxMeaning
`json:"name"`Tag: field appears as "name" in the JSON.
`json:"-"`Field is never included.
`json:"age,omitempty"`Omit the field when it holds the zero value.
No tagJSON key is the field name verbatim: "Name".
Lowercase fieldInvisible to encoding/json — silently skipped.

JSON to struct (decode)

var p person
err := json.NewDecoder(r.Body).Decode(&p)  // from an HTTP request
err = json.Unmarshal(data, &p)             // from a []byte

Decoding fills exported fields whose names (or tags) match the JSON keys, case-insensitively; unknown keys are ignored, missing ones keep their zero value. Always decode into a pointer — &p — so the changes land in your variable.

In an HTTP handler

w.Header().Set("Content-Type", "application/json")
json.NewEncoder(w).Encode(people)

Go's JSON keys match tags exactly — set them lowercase, the way the web expects ("name", not "Name").
