Go quick reference

CLI flags

The standard flag package binds command-line flags to variables — define, parse, dereference.

Define and parse

name := flag.String("name", "world", "who to greet")
count := flag.Int("count", 1, "how many times")
shout := flag.Bool("shout", false, "greet loudly")
flag.Parse()
fmt.Println(*name, *count, *shout)
SyntaxMeaning
flag.String/Int/Bool(...)Define a flag: name, default, help text; returns a pointer — use *name to read the value.
flag.StringVar(&target, ...)Binds to an existing variable instead; no pointer dance.
flag.Parse()Reads the command line; must run before values are real.
flag.Args()Leftover non-flag arguments, as a []string.
-h / --helpPrints every flag with its default and help text, automatically.

Usage notes

Flags come before positional arguments: tool -name Ada file.txt — file.txt lands in flag.Args(). Bool flags are true when present alone (-shout) and need -shout=false to stay false explicitly. An unknown flag exits with a usage message. One dash or two, Go accepts both (-name, --name).

Below flag sits os.Args — the raw argument slice, os.Args[0] being the program name. Use flag unless you need something it cannot express.
