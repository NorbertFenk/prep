# Mission

## Why this matters

I want to learn the Go programming language well enough to read, write, and
run small useful programs, then grow toward real tools and services.

## What success looks like

- I can explain the shape of a Go program.
- I can write and run a small Go program without copying blindly.
- I can use Go's core tools and documentation to keep learning independently.

## Current focus

Start with the smallest complete program: package, entry point, import, and
output. Refine this mission as practical goals become clearer.
