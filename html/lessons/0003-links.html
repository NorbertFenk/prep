HTML / Lesson 3

Links: the web's reason to exist

Hyperlinks are what makes the Web a web. No links, no web. They're also where paths, accessibility, and honesty all intersect — interviewers love them.

~25 min · prereq: 0002

The anatomy

<p><a href="https://www.firefox.com/">Download Firefox</a></p>

<a> — the anchor — wraps content and turns it into a link. The href attribute holds the destination URL. title adds a hover tooltip of supporting information.

Paths: same directory, down, up

<a href="contacts.html">                    <!-- same directory -->
<a href="projects/index.html">              <!-- down into a subdirectory -->
<a href="../pdfs/project-brief.pdf">        <!-- up one level, then down -->
<a href="https://www.some-other-site.com">  <!-- absolute: another site -->

Internal links (your own site) should use relative paths — if the site moves domains, relative paths keep working and absolute ones all break. External links need the full URL: the browser can't find another site from a path alone.

Fragments: link to the middle of a page

Any element with an id can be linked to with a #fragment:

<h2 id="mailing_address">Mailing address</h2>
<p>Use our <a href="contacts.html#mailing_address">mailing address</a>.</p>
<p>Or jump to our <a href="#mailing_address">address on this page</a>.</p>

Email links

<a href="mailto:whales@example.com?subject=Question%20about%20Whales">email us</a>

The mailto: scheme opens the visitor's mail client; query-style parameters prefill subject, cc, body. Spaces in values must be percent-encoded (%20).

Link text is content, not decoration

1
Say where the link goes

Screen reader users jump from link to link, out of context — a page of "click here" links is unusable. Search engines index link text too.

2
Signpost surprises

Linking a 4MB PDF? Say so: "download our factfile (PDF, 4MB)". Low-bandwidth users deserve the warning.

3
Never repeat the URL as text, never say "link"

Both are noise: screen readers already announce links, and URLs read aloud letter-by-letter are painful.

Exercise 1 — the real MDN task (Links 1)

Fix the two links on a whales information page: the first should go to whales.html (same directory) with a tooltip saying the page covers Blue Whales and Sperm Whales; the second should open an email to whales@example.com with the subject "Question about Whales":

<h1>Information on Whales</h1>

<p>
  For more information on our conservation activities and which Whales we study,
  see our <a>Whales page</a>.
</p>

<p>
  If you want to ask our team more questions, feel free to <a>email us</a>.
</p>

Whales page</a>

<a href="mailto:whales@example.com?subject=Question%20about%20Whales">
email us</a>

4. Why is "click here" bad link text?

5. What must spaces in a mailto subject line become?
