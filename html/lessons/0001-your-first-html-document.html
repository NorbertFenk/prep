Your first HTML document

You already know what happens to a page after the browser receives it (see the rendering lesson). Today you build the thing it receives: a complete HTML document, on purpose.

Write it yourself

Create a file called index.html, type this in — typing, not pasting, is the point — then open it in your browser:

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My test page</title>
  </head>
  <body>
    <h1>Some music</h1>
    <p>I really enjoy <strong>playing the drums</strong>.</p>
    <img src="https://www.cygnus-x1.net/links/rush/images/albums/sectors/sector2-movingpictures-cover-s.jpg" alt="Rush Moving Pictures album cover" width="300">
  </body>
</html>

Save, switch to the browser, refresh. Edit the text, refresh again. This loop — save, refresh, look — is the entire development cycle for this course.

What each part is for

1
<!doctype html>

A historical artifact that must still be present: it used to link to a rulebook the page promised to follow. <!doctype html> is the shortest valid string, and it's all you'll ever need.

2
<html lang="en"> — the root

Wraps everything. The lang attribute tells search engines and screen readers which language the page speaks — screen readers pronounce six differently in French and English.

3
<head> — the part nobody sees

Metadata: what the page is. <meta charset="utf-8"> declares the character encoding so any human language renders correctly. <title> is the browser-tab text, the bookmark name, and the headline in search results.

4
<body> — the part everybody sees

All content: text, images, video, everything displayed. In the example, <h1> marks a top-level heading, <p> a paragraph, <strong> gives a word strong importance, and <img> embeds an image.

Elements, tags, attributes

An element is the complete package: opening tag, content, closing tag. The element is the meaning ("this is a paragraph"); the tag is just its punctuation. Attributes live in the opening tag: name="value", separated by spaces:

<p>My cat is <strong>very</strong> grumpy.</p>
<img src="cat.jpg" alt="A grumpy cat" width="300">

Two rules that prevent most early bugs: nest, don't overlap — close things in the reverse order you opened them — and always quote attribute values. title=The Mozilla homepage silently becomes three attributes: title="The" plus boolean Mozilla and homepage.

A few elements have no content to wrap, so they have no closing tag — void elements: <img>, <br>, <meta>, <link>. You'll also meet boolean attributes like disabled that are true just by being present.

Check yourself (instant feedback)

1. What does <meta charset="utf-8"> do?

2. What appears in the browser tab, the bookmark, and the search result?

3. Which is correctly nested?

4. Why always quote attribute values?

5. Which of these is a void element?

6. What is the doctype for?
