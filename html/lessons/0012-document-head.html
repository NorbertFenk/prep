What's in the head?

The <head> is the part of the page nobody sees and everything uses: the browser, search engines, social networks, screen readers. You've written its skeleton since lesson 1 — now meet everything that lives there.

~25 min · prereq: 0001, 0009

<title> is not <h1>

The <h1> is the title of the page's content; the <title> is metadata for the document itself. It's the browser-tab text, the default bookmark name, and the headline of your search result. Different things, both required.

<meta>: name/content pairs

<meta charset="utf-8">                         <!-- encoding: always -->
<meta name="author" content="Chris Mills" />
<meta name="description"
      content="A complete beginner's guide to getting started with the web." />

The description is what search engines show under your link — your one honest sentence of marketing. (The old keywords meta is dead: spammers stuffed it, search engines ignore it.)

Social networks read Open Graph properties — that's why shared links sprout images and titles:

<meta property="og:title" content="Mozilla Developer Network" />
<meta property="og:description" content="…information about Open Web technologies…" />
<meta property="og:image" content="https://developer.mozilla.org/mdn-social-share.png" />

Icons, CSS, and JavaScript

<link rel="icon" href="/favicon.ico" type="image/x-icon" />

<link rel="stylesheet" href="my-css-file.css" />

<script src="my-js-file.js" defer></script>
1
<link rel="icon">

The favicon in the tab and bookmarks bar. Most browsers also auto-find /favicon.ico — the explicit link is for anything custom.

2
<link rel="stylesheet">

How CSS attaches: rel says what the resource is, href where it is. Always in the head.

3
<script src="…" defer>

defer runs the script only after the HTML has fully parsed — the reliable modern default, so your JS never grabs an element that doesn't exist yet. Note <script> is not a void element: it needs its closing tag.

lang: the whole page's accent

<html lang="en-US">
  …
  <p>Japanese example: <span lang="ja">ご飯が熱い。</span>.</p>

Set the document language on <html> (search indexing, correct screen-reader pronunciation); switch languages inline with lang on the spanning element.

Exercise — from the real MDN challenge (Marking up a letter, head part)

Build just the head of the university-letter document: UTF-8 charset, the author "Dr. Eleanor Gaye" in a meta tag, language en-US, title "Awesome science application correspondence", and this CSS in the appropriate element:

body { font: 1.2em / 1.5 system-ui; }
.sender-column { text-align: right; }
h1 { font-size: 1.5em; }
h2 { font-size: 1.3em; }
Show solution 
<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <meta name="author" content="Dr. Eleanor Gaye" />
    <title>Awesome science application correspondence</title>
    <style>
      body {
        font: 1.2em / 1.5 system-ui;
      }

      .sender-column {
        text-align: right;
      }

      h1 {
        font-size: 1.5em;
      }

      h2 {
        font-size: 1.3em;
      }
    </style>
  </head>
  <body>
    <!-- the letter body, from the full challenge on MDN -->
  </body>
</html>
