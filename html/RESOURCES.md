# HTML Resources

## Knowledge

- [MDN: Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content) (verified 2026-09-18)
  The core MDN module — element anatomy, text, links, images, tables, forms,
  debugging. Every lesson's exercises come from here. Use for: primary
  reference for all 11 content chapters; its "Test your skills" and challenge
  pages are transcribed in this course.
- [MDN: Basic HTML syntax](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax) (verified 2026-09-18)
  Element anatomy, nesting, void elements, attributes, document skeleton.
  Use for: lessons 1–2 grounding.
- [MDN: Web page metadata](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Webpage_metadata) (verified 2026-09-18)
  `<title>` vs `<h1>`, `<meta>` types, favicon, CSS/JS attachment, `lang`.
  Use for: lesson 12.
- [MDN: Debugging HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Debugging_HTML) (verified 2026-09-18)
  Why browsers fix bad HTML silently, the DOM inspector, validator workflow.
  Use for: lessons 10 and 12.
- [MDN: HTML — A good basis for accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/HTML) (verified 2026-09-18)
  Semantic hooks, alt text, link text, form labels, empty alt, skip links.
  Use for: lesson 11.
- [MDN: WAI-ARIA basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/WAI-ARIA_basics) (verified 2026-09-18)
  Roles, landmarks, live regions — and when *not* to reach for ARIA.
  Use for: lesson 11.
- [WHATWG HTML Living Standard](https://html.spec.whatwg.org/) (verified 2026-09-18)
  The single normative spec. Use for: settling disputes about what an element
  means — not for learning.
- [MDN: All HTML elements reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements) (verified 2026-09-18)
  Per-element syntax, attributes, examples. Use for: looking up anything the
  course doesn't cover.
- [web.dev: Learn HTML](https://web.dev/learn/html) (verified 2026-09-18)
  Google's guided HTML path. Use for: a second voice when MDN's framing
  doesn't land.
- [W3C: An alt Decision Tree](https://www.w3.org/WAI/tutorials/images/decision-tree/) (verified 2026-09-18)
  Official flowchart for choosing alt text. Use for: lesson 11, the empty-alt rule.
- [WebAIM](https://webaim.org/) (verified 2026-09-18)
  Practitioner-focused accessibility guides and articles. Use for: depth beyond MDN.

## Wisdom (Communities)

- [r/webdev](https://www.reddit.com/r/webdev/) — large beginner-friendly web dev
  community. Use for: markup critiques, "is this semantic?" sanity checks.
- [MDN Community channels](https://developer.mozilla.org/en-US/docs/MDN/Community/Communication_channels)
  (MDN Discord) — where MDN contributors and learners hang out. Use for:
  asking the people who write the docs.
