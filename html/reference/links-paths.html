Links & paths

The <a> anchor: the element that makes the Web a web.

Anatomy

Path types

hrefGoes to
contacts.htmlSame directory (optional ./ prefix).
projects/index.htmlDown into a subdirectory.
../pdfs/brief.pdfUp one level, then down (stack: ../../).
/pdfs/brief.pdfRelative to the site root.
https://site.com/pageAbsolute: another site, full URL required.
page.html#sectionFragment: the element with id="section".
#sectionFragment in the current page.
mailto:you@example.com?subject=Hi%20thereEmail draft; query params prefill subject/cc/body; spaces are %20.

Internal links → relative paths (survive domain moves). External links → absolute URLs (browser can't find another site from a path).

Link text rules

  • Say where the link goes: screen readers jump link-to-link out of context; search engines index link text.
  • Never "click here", never "link", never the raw URL.
  • Signpost surprises: "download our factfile (PDF, 4MB)".
  • Same link text → same destination (never two "click here"s going different places).
  • download attribute: forces download, optionally suggests a filename.
