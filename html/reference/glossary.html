HTML quick reference

Glossary — HTML

Terms used across all lessons. One line each — interview-answer length.

HTML (HyperText Markup Language)
The markup language that structures web pages: a tree of elements, each carrying meaning, not appearance.
Element
Opening tag + content + closing tag — the complete unit of meaning ("this is a paragraph").
Tag
The punctuation of an element: the angle-bracket names marking where it starts and ends.
Attribute
name="value" extra information in the opening tag — href, src, alt, id.
Boolean attribute
An attribute true by presence alone: disabled, required, controls, defer.
Void element
An element with no content and no closing tag: img, br, meta, link, input. (Not script.)
Doctype
<!doctype html> — historical rulebook pointer, still required, first line of every page.
Semantic markup
Choosing elements for what content is, not how it should look — consumed by screen readers, search engines, and future maintainers.
Presentational element
Elements that only say how text looks (font, big); deprecated — style is CSS's job.
Landmark
A structural region (header, nav, main, footer) exposed by screen readers as jump targets.
Root element
<html> — wraps everything; carries the page's lang.
Head / metadata
The invisible part of the document: encoding, title, description, CSS/JS links, icons.
Meta element
<meta> — document metadata as name/content pairs (charset, author, description) or Open Graph properties.
Open Graph
Meta protocol (og:title, og:image…) that social networks read to render share cards.
Alt text
The alt attribute: the text stand-in for an image. Content → describe it; decoration → empty (alt="", never missing); in a link → the destination.
Screen reader
Assistive technology that reads the page aloud and navigates by headings, landmarks, and form labels — the silent consumer of all your semantics.
Fragment
A link target inside a page: #id jumps to the element with that id.
Relative / absolute path
Location relative to the current document (../pdfs/b.pdf) vs a full URL. Internal links: relative — they survive domain moves.
Anchor
The <a> element with href — the link. No web without it.
Mailto link
href="mailto:…" opens a mail draft; query params prefill subject/cc/body, spaces percent-encoded.
Container / codec
A media file's wrapper (MP4, WebM) / the algorithm that encoded its tracks (H.264, VP9). Browsers support different sets → multiple <source>s.
WebVTT
Subtitle/caption file format attached via <track>, with srclang and label.
SVG
XML markup describing vector shapes — resolution-independent graphics; embed via <img> or inline.
Replaced element
An element whose content comes from an external resource (img, video), not from its own children.
Table caption
<caption> — the whole table's title, visible to every user.
scope
<th scope="col|row|colgroup|rowgroup"> — declares what a header cell labels, so screen readers can announce cell-by-cell context.
Rowspan / colspan
Attributes letting a cell span multiple rows/columns — how group headers cover their sections.
Label (form)
<label for> ↔ id: the contract naming a control. Announced by screen readers; clicking the label focuses the control.
Fieldset / legend
<fieldset> groups related controls; <legend> names the group — announced alongside each control inside it.
Client-side validation
Browser-enforced constraints (required, typed inputs, length bounds) that block submission — UX, not security.
Browsing context
A browser's independent document environment — each <iframe> creates its own.
Sandbox
<iframe sandbox>: maximum restriction by default (no scripts, forms, popups); add permissions back one at a time.
Clickjacking
Attack where invisible frames capture clicks; defended by sandboxing and X-Frame-Options/CSP headers.
X-Frame-Options
Response header a server sends to forbid being framed by other sites — why some pages refuse to embed.
Permissive parsing
Browsers never show HTML syntax errors — they silently repair bad markup per fixed rules. You get a page, but not necessarily yours.
DOM (Document Object Model)
The parsed tree of the page — what the browser builds (from possibly repaired markup) and what CSS and JavaScript act on.
Validator
The W3C Markup Validation Service — the tool that reports what permissive parsing hides. Green banner or it doesn't ship.
Character reference
Escape codes for syntax characters: &lt;, &gt;, &amp;, &quot;, &apos;.
Viewport meta
<meta name="viewport" content="width=device-width, initial-scale=1"> — tells mobile browsers to render at device width.
Defer
<script defer> — download now, run after the HTML finishes parsing: JS never grabs a missing element.
Favicon
The tab/bookmark icon, via <link rel="icon"> or an auto-found /favicon.ico.
