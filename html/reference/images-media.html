HTML quick reference

Images & media

<img>, <figure>, <video>, <audio> — and the alt decision tree.

<img> attributes

AttributeFor
srcPath/URL — required. Relative for your own files; never hotlink others' images without permission.
altText stand-in for those who can't see it. Content → brief description. Decoration → alt="" (empty, never missing). In a link → describe the destination.
width/heightReserve the box: no layout reflow when the image arrives.
titleHover tooltip; never a substitute for alt.

<video> / <audio>

Attribute / elementFor
controlsBrowser's play/pause/volume UI — users must be able to stop playback.
<source src type>Multiple formats; type (MIME) lets the browser skip unsupported ones without downloading.
fallback contentInside the element, non-<source>: shown when media can't play (e.g. a download link).
autoplay + mutedMust pair: silent autoplay only; browsers (and users) reject noisy autoplay.
loop · preload="auto|metadata|none"Restart forever · how eagerly to buffer.
poster · width/heightVideo only — splash image and box size.
<track kind="subtitles" srclang label>WebVTT captions/subtitles; srclang + label identify the language in the menu.

Vocabulary: a media file is a container (MP4, WebM) holding tracks encoded by a codec (H.264, VP9).

SVG: two ways in

ViaTrade-off
<img src="logo.svg">Cached, alt works — but no CSS/JS access to the shapes.
Inline <svg>…</svg>Shapes join the DOM: styleable, animatable — but no caching, bloats each page.
