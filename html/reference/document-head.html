HTML quick reference

Document head

The metadata container: what the browser, search engines, and social networks know before they render anything.

The residents

ElementFor
<title>Tab text, bookmark name, search-result headline. Titles the document; <h1> titles the content.
<meta charset="utf-8">Character encoding — always first in the head.
<meta name="author" content>Who wrote the page.
<meta name="description" content>The sentence search engines show under your link. (The keywords meta is dead — spammers killed it.)
<meta property="og:*" content>Open Graph: og:title, og:description, og:image — the card shown when the page is shared.
<link rel="icon" href>Favicon (tab, bookmarks). Browsers also auto-find /favicon.ico.
<link rel="stylesheet" href>Attaches CSS. Always in the head.
<script src defer>Attaches JS. defer runs it after the HTML finishes parsing — the reliable default. Not a void element: needs </script>.

Language

<html lang="en-US">
  <p>Japanese example: <span lang="ja">ご飯が熱い。</span>.</p>

Document language on <html> (search indexing, screen-reader pronunciation); inline switches with lang on the spanning element.

Minimal production head

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="One honest sentence.">
  <title>Page title</title>
  <link rel="stylesheet" href="style.css">
  <script src="app.js" defer></script>
</head>
