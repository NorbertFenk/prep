HTML quick reference

Text semantics

Inline and block elements that say why text is different — style is CSS's job.

Structure

ElementMeaning
<h1>–<h6>Document outline. One <h1>, no skipped levels; size is CSS's job.
<p>Paragraph.
<ul>/<ol>/<li>Lists: order doesn't matter / order matters / item. Nav menus are <ul>s of links.
<dl>/<dt>/<dd>Description list: term / description pairs (glossaries, FAQs, metadata).
<hr>Thematic break between topics.
<br>Line break for fixed short lines (addresses, verse) — not for spacing.

Inline semantics

ElementMeaningUse when
<em>Stressed emphasisThe spoken stress would change the sentence ("I might").
<strong>Strong importanceWarnings, key terms — words that genuinely matter.
<b>Bold-look keywordsOnly when no better element exists (product names, lead sentences).
<i>Italic-look offsetForeign words, technical/scientific terms, thoughts.
<u>Underline-look annotationRare: misspellings, proper names. Never for links look-alikes.
<mark>Relevance highlightText highlighted for the current context (search matches).

<font>, <big>, <center>: presentational, deprecated, never use.

Quotations, terms, machines

ElementMeaning
<blockquote cite="URL">Block-level quote; cite records the source URL (not displayed).
<q cite="URL">Short inline quote; browsers add quote marks.
<cite>The title of the work being cited.
<abbr title="expansion">Acronym/abbreviation with tooltip expansion.
<address>Contact info for the nearest <article>/<body> — not any postal address.
<time datetime="2019-12-25">Machine-readable date/time; ISO format in the attribute.
<sub>/<sup>Chemical subscripts, exponents, ordinals — semantics, not just looks.
<code>Inline code snippet.
<pre>Preserves whitespace; pair as <pre><code> for code blocks.

Canonical example

<p>In drama, a <em>soliloquy</em> — from Latin
<i lang="la">solo</i> — matters <strong>hugely</strong>.
It appears in <abbr title="HyperText Markup Language">HTML</abbr>
docs since <time datetime="1991-08">August 1991</time>.</p>
